# 🎓 CampusLeuth

### Lost Something? Let's Find It.

CampusLeuth is a campus-based Lost and Found platform designed to help students report, search, and recover lost belongings within their university campus.

## 🎯 Project Objective

The main objective of CampusLeuth is to create a centralized platform where students can easily report lost or found items instead of depending on WhatsApp groups or informal communication.

## ✨ Features

* Report lost items.
* Report found items.
* Search for lost and found belongings.
* View recently reported items.
* User-friendly interface.
* Dark-themed modern UI.

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

## 🚀 Future Enhancements

* Student authentication.
* User dashboard.
* Image uploads.
* Advanced search and filters.
* Claim and recovery system.
* Backend integration.
* MongoDB database.

## 🎓 Target Audience

Initially designed for Bennett University students, with the possibility of expanding to other universities.
